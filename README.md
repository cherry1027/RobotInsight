# RobotInsight

A React/TypeScript prototype focused on recycling-robot performance, vision annotation, and data quality.

> Synthetic demonstration data 

## Features

- **Operations Dashboard:** Pick attempts, success rate, failed picks, detection failures, cycle time, vision confidence, and uptime.
- **Vision Annotation:** Synthetic conveyor schematics with Plastic, Metal, Cardboard, Glass, and Unknown labels; Correct, Incorrect, Occluded, and Uncertain review statuses.
- **Robot Logs:** Timestamped events with robot, time-range, event-type, and text filters.
- **Behavior Analysis:** Deterministic material success rates, failure causes, cycle-time trends, low-confidence detections, and supporting log evidence.
- **Data Quality:** Missing labels, synthetic duplicate-frame indicators, uncertain annotations, class distribution, and review consistency.
- **CSV Export:** Download the selected synthetic pick data.

## Tech Stack

- React
- TypeScript
- CSS
